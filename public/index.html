Add a grading cost

Log what you paid to grade a card — it rolls into that card's cost basis automatically, so P&L and on-hand value both account for it.

Grading Review (beta) — before you submit

A photo-based read on centering, surface, corners, and edges, front and back, with rough per-company grade ranges. This is an estimate to help you decide what's worth the submission fee, not an official grade.

For the best read:
  • Flat, even lighting — no flash glare, a plain neutral background
  • Camera held parallel to the card, not tilted (tilt throws off centering)
  • Card fills the frame with a small margin, both corners fully visible
  • Back photo strongly recommended — back centering is graded separately and affects the result

Automatic backups

The site snapshots your data once a day automatically, kept for 30 days — this is a safety net for in-app mistakes, not a replacement for occasionally clicking Export data and saving that file somewhere off the site.

Restore from backup

If data ever gets wiped, upload an Export data file (or a downloaded backup from above) here to restore it. This replaces everything currently in the site — your current state gets snapshotted first as a safety net, but only use this when you mean to overwrite.
